# IP Review Checklist

Status: project governance checklist.
Updated: 2026-05-08.

Use this checklist before publishing potentially patentable, commercially
sensitive, or strategically important NanoClaw ideas. This is project hygiene,
not legal advice.

## When To Use This Checklist

Use IP review before publishing a draft that includes:

- a new technical mechanism;
- a novel agent approval workflow;
- a distinctive provenance or receipt method;
- a collection/NFT publication mechanism with possible commercial value;
- a security, runtime, orchestration, or integration design that is more than
  educational explanation;
- any idea where patent, defensive publication, or trade-secret strategy may
  matter.

## Quick Classification

| Material | Default decision |
| --- | --- |
| Educational material | Publish open source when public-safe |
| Research material | Publish as source-backed notes |
| Potentially patentable idea | IP review first |
| Strategic/commercial material | Keep private |
| Third-party material | Link, cite, and annotate |
| Important publication | Release |
| Key idea | Timestamped whitepaper |
| Strong technical solution | Consider provisional patent review |
| Method/text | Copyright notice where appropriate |
| Code | Repository open-source license |

## Commercial Sensitivity

Keep private if the draft includes:

- pricing;
- buyer or collector outreach;
- partner negotiations;
- sponsor targets before public confirmation;
- investment thesis;
- product positioning that is not ready;
- private collection source assets;
- wallet, payment, or custody operations;
- DNS or account-control procedures.

## Publication Decision

Choose one:

| Decision | Meaning |
| --- | --- |
| `publish-open-source` | Safe educational or implementation material |
| `publish-source-backed-note` | Research with sources and verification status |
| `publish-defensive-whitepaper` | Intentional timestamped public disclosure |
| `hold-private` | Strategic, commercial, or sensitive material |
| `seek-provisional-patent-review` | Potentially patentable technical solution |
| `revise-before-publication` | Needs redaction or reframing |

## Hard Stop

Do not publish if the draft contains:

- private collection source assets;
- buyer, collector, or partner private data;
- wallet credentials, wallet addresses, seed phrases, API keys, webhooks, or
  tokens;
- local private paths;
- prices or auction strategy;
- unreviewed legal, rights-clearance, custody, yield, investment, or
  partnership claims.
