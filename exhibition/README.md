# NanoClaw Exhibition Pack

This folder contains public-safe templates for presenting NanoClaw as a small
technical exhibition. Do not place private collection files, high-resolution
source images, contracts, invoices, or private certificates here.

Recommended public path:

1. use `catalog-card-template.md` for one redacted/sample object;
2. use `demo-script.md` for a short public walkthrough;
3. use `partner-note.md` when inviting feedback;
4. keep real rights records outside this public repository unless publication
   is intentional.
